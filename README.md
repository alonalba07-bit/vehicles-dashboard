# Dashboard de anuncios de vehículos

## Descripción del proyecto

Este proyecto consiste en el desarrollo y despliegue de una aplicación web interactiva construida con Streamlit, que permite explorar un conjunto de datos de anuncios de venta de vehículos.

La aplicación utiliza visualizaciones interactivas desarrolladas con Plotly para facilitar la exploración de los datos.

## Funcionalidades

- Visualización de un histograma para analizar la distribución del kilometraje de los vehículos.
- Gráfico de dispersión para explorar la relación entre el kilometraje y el precio.
- Interfaz interactiva mediante botones.
- Visualización de gráficos desde un navegador web.

## Tecnologías utilizadas

- Python
- Pandas
- Plotly
- Streamlit
- Git y GitHub
- Render

## Estructura del proyecto

- `app.py`: aplicación web.
- `vehicles_us.csv`: conjunto de datos.
- `requirements.txt`: librerías necesarias.
- `notebooks/EDA.ipynb`: análisis exploratorio.

## Ejecución local

Instalar las dependencias:

```bash
pip install -r requirements.txt
```

Ejecutar la aplicación:

```bash
streamlit run app.py
```
